איך הדוור יודע לאן ללכת?

כתובות MAC שלמדנו עליהן בשיעור 3 הן מעולות למסגרת המקומית (אותו הרחוב). אך מה קורה כשצריך להעביר חבילה ממדינה אחת למדינה אחרת? אם הדוור היה צריך לעבור בית-בית בכל העולם ולבדוק כתובת MAC ייחודית – כל מערכת הדואר העולמית הייתה קורסת. בשביל זה נוצרה IP (Internet Protocol). היא כתובת לוגית בעלת מבנה היררכי המאפשרת ניתוב גלובלי מהיר.

תיאוריה חיונית

איך מפרידים בין "הרחוב" לבין "הבית"?

כתובת IPv4 מורכבת מ-32 סיביות (Bits) המחולקות ל-4 מספרים בין 0 ל-255 המופרדים בנקודה (למשל 192.168.1.50). אבל איך המחשב יודע איזה חלק מהכתובת מייצג את ה**רשת (Network)** ואיזה חלק מייצג את ה**מכשיר (Host)**? כאן נכנסת לתמונה **מסכת הרשת (Subnet Mask)**!

מבנה חלוקה קלאסי מסוג Class C:
חלק המארח (Host ID) 50 מוגדר על ידי ה-0 במסכת הרשת
.
חלק הרשת (Network ID) 192.168.1 מוגדר על ידי ה-255.255.255 במסכה

טבלת מחלקות (Classes) ופרפיקסים (CIDR) - מסודרת:

מחלקה (Class) טווח אוקטטה ראשונה מסכת ברירת מחדל פרפיקס CIDR
Class A 1 - 126 255.0.0.0 /8
Class B 128 - 191 255.255.0.0 /16
Class C 192 - 223 255.255.255.0 /24

מסכת רשת של 255.255.255.0 (פרפיקס /24) קובעת כי 24 הביטים הראשונים שייכים לרשת. מספר המארחים מחושב לפי הנוסחה: 2H - 2. עבור 8 ביטים של מארח: 28 - 2 = 254 כתובות זמינות.
