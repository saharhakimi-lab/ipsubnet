לומדים כתובות IP עם סהר

כתובות IP ותת-רשתות: השכבה השלישית מתעוררת לחיים. למד כיצד מנותבות חבילות מידע ברשת העולמית וכיצד מפרידים בין רשתות ומארחים.

01 — אתגר השכבה השלישית

מעבר חבילת תקשורת והדמיון לעבודת הדוור

כתובות MAC שייכות לשכבת הערוץ ומעולות למסגרת המקומית (באותו הרחוב). אך מה קורה כשצריך להעביר חבילה ממדינה אחת למדינה אחרת? אם הדוור היה צריך לעבור בית-בית בכל העולם ולבדוק כתובת ייחודית – כל מערכת הדואר העולמית הייתה קורסת. בשביל זה נוצרה IP (Internet Protocol) - כתובת לוגית בעלת מבנה היררכי המאפשרת ניתוב גלובלי מהיר.

🌍 קוד המדינה (רשת)

מגדיר באיזו רשת גלובלית או מדינה החבילה נמצאת כעת.

🏙️ שם הרחוב (תת-רשת)

מצמצם את המיקום לשכונה או רחוב ספציפי בתוך הרשת המרכזית.

🏠 מספר הבית (Host)

המחשב, הטלפון או המכשיר הספציפי הנמצא בתוך אותה רשת.

❓ שאלה למחשבה: התנגשות כתובות (IP Conflict)

מה קורה אם לשני מחשבים שונים באותו רחוב, ברשת מקומית, תהיה אותה כתובת IP בדיוק?

02 — אינטואיציית המסכה ותת-הרשתות

איך מפרידים בין הרחוב לבין הבית?

כתובת IPv4 מורכבת מ-32 סיביות (Bits) המחולקות ל-4 מספרים בין 0 ל-255 המופרדים בנקודה. מסכת הרשת (Subnet Mask) היא הבלופרינט שמורה למחשב איזה חלק מהכתובת שייך לרשת ואיזה חלק שייך למארח.

מבנה חלוקה קלאסי מסוג Class C:

192.168.1
חלק הרשת (Network ID) - מוגדר ע"י 255.255.255
50
חלק המארח (Host ID) - מוגדר ע"י 0 במסכה

טבלת מחלקות (Classes) ופרפיקסים (CIDR):

מחלקה טווח אוקטטה ראשונה מסכת ברירת מחדל פרפיקס CIDR
Class A 1 - 126 255.0.0.0 /8
Class B 128 - 191 255.255.0.0 /16
Class C 192 - 223 255.255.255.0 /24

נוסחת חישוב מספר המארחים ברשת: 2H - 2. עבור 8 ביטים של מארח (/24): 28 - 2 = 254 כתובות זמינות.
