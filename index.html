02 — אינטואיציית המסכה ותת-הרשתות

איך מפרידים בין הרחוב לבין הבית?

כתובת IPv4 מורכבת מ-32 סיביות Bits המחולקות ל-4 מספרים בין 0 ל-255 המופרדים בנקודה. מסכת הרשת Subnet Mask היא הבלופרינט שמורה למחשב איזה חלק מהכתובת שייך לרשת ואיזה חלק שייך למארח.

מבנה חלוקה קלאסי מסוג Class C:

192.168.1
חלק הרשת Network ID - מוגדר ע"י 255.255.255
50
חלק המארח Host ID - מוגדר ע"י 0 במסכה

טבלת מחלקות Classes ופרפיקסים CIDR:

מחלקה טווח אוקטטה ראשונה מסכת ברירת מחדל פרפיקס CIDR
Class A 1 - 126 255.0.0.0 /8
Class B 128 - 191 255.255.0.0 /16
Class C 192 - 223 255.255.255.0 /24

נוסחת חישוב מספר המארחים ברשת: 2H - 2. עבור 8 ביטים של מארח /24: 28 - 2 = 254 כתובות זמינות.

03 — מעבדת דיאגנוסטיקה וניתוח

סימולטור תקשורת בין רשתות ופתרון תקלות

במעבדה הזו אתם טכנאי הרשת. בחרו תרחיש, בדקו את ההגדרות, ואז תקנו את התקלה בעצמכם. בכל בדיקה תראו מה עבר, היכן נעצרה החבילה ולמה.

שלב 1: בחרו מצב עבודה

אפשר להתחיל מתרחיש תקלה ולחקור אותו, או לבחור רשת תקינה ולשנות הגדרה כדי לראות מה קורה.

המשימה שלכם: בדקו קודם תקשורת אל הנתב המקומי Gateway של רשת A. לאחר מכן בדקו תקשורת אל PC B שברשת המרוחקת. אם הבדיקה נכשלת, קראו את ההסבר ותקנו את השדות של PC A.
רשת B · 10.0.0.0/8 — הרשת המרוחקת רשת A · 192.168.1.0/24 — הרשת המקומית

שלב 2: הגדרות PC A

ערכו את הערכים ובדקו כיצד הם משפיעים על יכולת המחשב לשלוח חבילות.

שימו לב: השער של PC A הוא 192.168.1.1 — הכתובת של ממשק הנתב שמחובר פיזית לרשת A. הכתובת 10.0.0.1 שייכת לממשק השני של הנתב, ברשת B, ולכן אינה שער מקומי תקין עבור PC A.
